# 🚀 Full Stack Web Application (React + Django REST)

This project is a fully responsive full-stack web application built using **React** for the frontend and **Django REST Framework** for the backend. It uses REST APIs to connect the user interface with the server and provides a modern, scalable architecture for web applications.

---

## ✨ Features

- Fully responsive UI
- React based frontend
- Django REST API backend
- JWT Authentication
- Secure API endpoints
- CRUD operations
- Clean and scalable architecture

---

## 🛠 Tech Stack

### Frontend
- React
- Tailwind CSS
- Axios
- React Router

### Backend
- Django
- Django REST Framework
- SimpleJWT
- PostgreSQL / SQLite
